🌟 为什么选择科研之路？

选择攻读博士学位是我人生中一个深思熟虑的决定，它源于我对个人抱负的清晰认知以及对有意义的智力探索的渴望。我在工业界不同岗位（包括研究型、业务型、工程型乃至更常规的职位）的经历，让我明确了自己对深度思考的偏爱，以及解决挑战性问题所带来的价值感和学术研究所能提供的相对自由。

💡 为什么选择读博？

我的抱负不止于个人成就；我希望能成为一名博导，有机会鼓励我的学生去做他们感兴趣且擅长的事情，那正是他们天赋所在。此外，我希望制作一份本领域从零开始学习的开源手册，打破“先有鸡还是先有蛋”的问题，给更多有想法的同学拓宽选择的机会。

🚀 并非惯性选择，亦无惧社会

我的选择并非惯性升学，更不是为了逃避进入社会。相反，我渴望社会化，并计划在博士期间注重这方面的训练。我的动力并非源于学历崇拜，而是真切地希望能做出有意义的贡献。

🎯 我是否适合科研？

我对研究的理解是：想法 -> 实验 -> 失败 -> 想法 -> ... -> 写作 -> 演示 -> 社交。 我发现自己非常享受这个过程中的每一个环节。无论是最初灵光乍现的想法，还是利用扎实的工程积累进行系统的实验，亦或是面对失败时那句轻松的“没事儿～”，我都乐在其中。写作对我而言是一种艺术——是讲述这份工作故事的过程，我热衷于关注行文逻辑的环环相扣，以及图表配色、布局的易读性和美观性（强迫症使我狂喜）。在许多人面前分享我的工作会让我感到兴奋和快乐，甚至有些“人来疯”（我想这与我小时候经常登台表演的经历有关）。我认为这是博士阶段需要持续培养的能力，在会议上流畅且有逻辑的表达是吸引潜在合作的宝贵时机。我曾尝试与公司里不同年龄段的陌生人进行“咖啡聊天”以了解他们的工作感悟，这让我具备了从容破冰的能力。此外，参加会议前我会提前宣传自己的工作，并关注其他感兴趣的研究，带着自己的理解和疑问，以便进一步寻求合作机会。

🌍 审视并拥抱潜在风险

我明白读博短期的经济收益肯定不如直接进入大厂工作，长期的经济回报更难以预料。然而，“好”不等于“合适”，我的实习经历已经证明了我更适合什么，而非所有事情都可以用性价比来衡量。

我深知自己可能会过于乐观，甚至在美化一条未走的路。未来，我可能只是一名普通的博士生，需要面对一无所获的不确定性、学历贬值的时代变化、年龄限制带来的教职焦虑（我还想读个博后）等诸多变化和困难。但是，我依然选择去做。能够花几年时间专注自己感兴趣的事情，在相对自由的时空里更好地了解自己，这本身就很难得。哪怕最后证明我所做的方向行不通，即便在社会评价体系中结果是失败的，那也获得了一份科学的结论。

💪 我的特质与方法

我的性格特点 (INFJ)

作为一名INFJ，我需要工作中的价值感，也会在不同的场合模仿需要的角色（外向的社交之后需要独处来充电）。我对自己的思维特点有着清晰的认识。我拥有超强的情绪共情和体感共情能力，因此无论未来代表哪一类人的利益，我都能持续传递善意，努力做一个有温度的人。

独特的认知优势

  • 我的**几何空间想象力和抽象概括能力**非常出色。我也很擅长观察和模仿，因为我能像孩童一样打量世界，思考其背后的“为什么”，在发现有意思的动机的同时，还能发现需求空缺（并进一步提问：为什么没人做？）。
  • 我的**直觉感**很强。我认为直觉是自我意识的感知，是长期思考的沉淀。我相信有影响力的工作的雏形往往是有趣的工作，而“有趣”本身就是一种感受。
  • 我喜欢有条理的**单线工作**，不喜欢并行处理事情。

应对挑战

我有时会因为害怕做不好而不敢开始，因恐惧而想要逃避行动。但我已经学会告诉自己：先完成再完美，先做一个乱七八糟的东西出来。

理想的博导画像

我寻找的导师，依旧记得当初做科研的初衷：愿与学生共赢、支持交流合作、活跃在学术一线（如果有鲜明的个人特点就更好了：情绪稳定？抽象有趣？……）。

我的优势

  • 我的读博动机和兴趣方向都是**斟酌后的自主选择**，因此会拥有更持久坚定的**内驱力**。
  • 我更懂得珍惜平台**资源**，理解个人能力上限的决定性因素是个人的努力和机缘，英雄不问出处，提升**自身实力**才是硬道理。
  • 我能够以更包容的**心态**看待问题。我的过往经历让我能以更平和的心态去面对困难和变化，**接纳**一切，允许事情没有理由地、不按期待地发生。毕竟这个世界就是一个巨大的随机种子。
